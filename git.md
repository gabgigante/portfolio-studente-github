Esercizio 1
comandi usati

1. mkdir portfolio-studente
2. cd portfolio-studente
3. touch index.html style.css README.md
4. start index.html
5. start style.css
6. start README.md
7. git init
8. git status
9. git add
10. git commit
11. git log
